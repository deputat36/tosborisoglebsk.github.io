Контур округа — картографический ориентир по OpenStreetMap, не юридическая граница. Нажмите «Показать улицы», чтобы увидеть улицы и дома.

Сохранение и проверка

Изменения сохраняются в этом браузере. Скачайте файл для резервной копии или другого устройства. Для общей публикации пришлите файл редактору проекта: границы проверяются отдельно.

Что отмечаем

Не указывайте личные телефоны, контакты жителей и закрытые сведения. Выбор документа сам по себе не подтверждает официальность контура.

Участки в моей разметке

    Правка вершин и координат

    Выбранные вершины можно двигать на карте. Для нового контура или точного ввода: по одной вершине в строке, сначала широта, затем долгота через пробел. Пример: 51.368015 42.075169.

    Как пользоваться картой

    1. Выберите ТОС. Для работы нажмите «Моя разметка».
    2. Приблизьте карту. Кнопка «Показать улицы» включает подложку OpenStreetMap.
    3. Нажмите «Нарисовать контур», отметьте углы территории и завершите кнопкой. На телефоне можно перемещать карту и добавлять вершины кнопкой «Точка в центре карты».
    4. Для отдельных частей одного ТОС нарисуйте несколько участков. Внутренний участок можно исключить кнопкой «Вырезать участок».
    5. Проверьте пересечения, скачайте файл и передайте его для общей публикации.

    Неразмеченная территория означает отсутствие контура на этой карте. Там может существовать ТОС, ещё не внесённый в разметку или каталог. До создания нового ТОС уточните действующий реестр, границы и возможность создания в администрации.

    Данные и сохранение

    Общая карта использует проверенные геоданные портала. Рабочие контуры и идеи хранятся на вашем устройстве; они не меняют общую карту посетителей. Файл разметки нужен для передачи и резервной копии. Площадь приблизительная; пересечения показывают геометрическое наложение схем, а не правовой спор.
