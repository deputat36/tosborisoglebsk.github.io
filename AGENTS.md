# Правила работы с проектом

## Репозиторий

- Работать в `deputat36/tosborisoglebsk.github.io`.
- Основная рабочая ветка: `release-2025-12-22`.
- Не считать `main` основной веткой без отдельного решения владельца.

## Перед изменениями

1. Прочитать `README.md`, `docs/PROJECT.md`, `docs/STATUS.md` и `docs/DECISIONS.md`, если они существуют.
2. Проверить существующую реализацию, данные, генераторы и GitHub Actions.
3. Найти все страницы и шаблоны, которые затронет задача.
4. Проверить связь материалов через `tos_slug`.

## Ограничения

- не создавать дублирующие карточки ТОС;
- не менять массово данные без проверки;
- не придумывать факты, имена, даты, суммы и адреса;
- неполные сведения помечать как требующие уточнения;
- не публиковать закрытую информацию;
- не хранить секреты в репозитории;
- сохранять единый стиль и мобильную адаптивность.

## После изменений

- проверить внутренние ссылки и пути к изображениям;
- проверить мобильное отображение;
- проверить `/audit/`;
- при структурных изменениях проверить sitemap;
- убедиться, что GitHub Actions не сломаны;
- обновить `docs/STATUS.md`;
- важные решения записать в `docs/DECISIONS.md`.
