Как использовать открытые данные

Данные можно использовать для проверки карточек, подготовки сводок, поиска пробелов, публикации новостей и планирования обновлений. CSV-файлы задач удобно открыть в Excel, Google Таблицах или отправить тем, кто помогает собирать сведения по ТОСам.

Открытые данные отражают состояние файлов сайта. Если сведения устарели или требуют исправления, отправьте уточнение через форму обновления.
