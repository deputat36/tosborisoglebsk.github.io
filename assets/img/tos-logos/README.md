# Логотипы ТОС

Сюда загружаются логотипы отдельных ТОСов.

Рекомендуемый формат:

- SVG — лучший вариант для сайта: лёгкий, чёткий, хорошо масштабируется.
- PNG — если логотип только картинкой.
- WEBP — если нужно уменьшить вес.

Рекомендуемые размеры для PNG/WEBP: 512×512 px или 800×800 px.

Название файла лучше делать по slug ТОС:

- `uyutnyy.svg`
- `gubari.png`
- `ulyanovka.webp`

После загрузки файла нужно указать путь в карточке ТОС в `data/toses.json` или через админку:

```json
"logo": "/assets/img/tos-logos/uyutnyy.svg"
```

Если логотипа нет, сайт покажет аккуратный круглый знак с инициалами ТОС.
