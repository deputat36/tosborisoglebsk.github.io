# Логотипы ТОС

Сюда загружаются реальные логотипы отдельных ТОСов.

## Как называть файлы

Файл должен называться так же, как `slug` ТОС в `data/toses.json`.

Примеры:

```text
bogana.png
vostochnyy.png
gubari.svg
mahrovka.jpg
uyutnyy.png
chkalovec.svg
```

## Поддерживаемые форматы

- SVG — лучший вариант для сайта: лёгкий, чёткий, хорошо масштабируется.
- PNG — если логотип только картинкой.
- JPG/JPEG — если другого исходника нет.
- WEBP — если нужно уменьшить вес.

Рекомендуемые размеры для PNG/WEBP: 512×512 px или 800×800 px.

## Как логотип подключается к карточке

Скрипт `scripts/sync_tos_logos.js` автоматически проверяет эту папку и прописывает найденный файл в поле `logo` нужной карточки ТОС.

Например, если есть файл:

```text
assets/img/tos-logos/bogana.png
```

то в `data/toses.json` будет указано:

```json
"logo": "/assets/img/tos-logos/bogana.png"
```

Если у одного ТОС лежит несколько файлов с разными расширениями, приоритет такой:

```text
svg → png → jpg → jpeg → webp
```

Если логотипа нет, сайт покажет аккуратный круглый знак с инициалами ТОС.
