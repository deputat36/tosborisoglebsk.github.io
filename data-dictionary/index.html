Ключевые поля карточки ТОС

Простое объяснение основных полей

slug — короткий идентификатор ТОС в адресе сайта. Например, по нему формируется ссылка вида /tos/slug/.

name — название ТОС для отображения на сайте.

location — населённый пункт или территория.

boundaries — описание границ территории, если они известны и подтверждены.

chairperson — председатель или контактное лицо, если сведения можно публиковать.

phone, email, social — только открытые контакты для публикации. Если разрешения на публикацию нет, поле лучше не заполнять.

description — краткое описание ТОС и его деятельности.

verification — статус проверки сведений: подтверждено, частично подтверждено, требует проверки, уточняется или устарело.

Поля материалов

Новости, проекты, потребности и результаты

id

Уникальный идентификатор материала. Используется в адресе страницы или для связи внутри сайта.

tos_slug

Привязка материала к конкретному ТОС. Если поле заполнено, материал можно показать в карточке этого ТОС.

status

Статус публикации. Материалы со статусом draft не должны показываться как опубликованные.

source_url

Ссылка на источник, если материал основан на открытой публикации или документе.

Осторожность при использовании данных

  • CSV и JSON отражают состояние файлов сайта на момент последней генерации.
  • Отсутствие телефона или соцсети не означает, что их нет — возможно, они просто не подтверждены для открытой публикации.
  • Рабочие заготовки нужно отличать от подтверждённых новостей и результатов.
  • Перед публикацией персональных контактов нужно понимать, что они действительно предназначены для открытого размещения.
