Проверка доступности домена

Основной домен `tosborisoglebsk.ru` открывается в веб-проверке и отдаёт главную страницу портала. Терминальные запросы из текущего окружения получают 403 с текстом ограничения вызовов, поэтому их нельзя считать доказательством недоступности сайта.

Что проверить вручную

  1. Открыть `https://tosborisoglebsk.ru/` в обычном браузере без VPN и с мобильной сети.
  2. Проверить, открывается ли `https://www.tosborisoglebsk.ru/`.
  3. Проверить, перенаправляет ли `http://tosborisoglebsk.ru/` на HTTPS.
  4. Проверить настройки GitHub Pages: custom domain, DNS check, enforce HTTPS.
  5. После изменения DNS подождать распространения и повторить проверку.

Что не считать ошибкой сайта

  • 403 только из текущего терминального окружения;
  • разницу между web-проверкой и terminal curl;
  • отсутствие DNS-ответа в `getent`, если веб-проверка успешно открывает сайт;
  • индексацию отдельных страниц без проверки основного домена.

Критерии готовности домена

  • основной HTTPS-домен открывает главную страницу;
  • HTTP-вариант перенаправляет на HTTPS;
  • `www` либо корректно открывается, либо предсказуемо перенаправляет на основной домен;
  • GitHub Pages показывает custom domain без DNS-ошибок;
  • после деплоя sitemap и ключевые страницы открываются по основному домену.
