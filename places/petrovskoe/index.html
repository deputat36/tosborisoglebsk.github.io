ТОС «Петровское»

ТОС «Петровское» объединяет жителей села Петровское для решения вопросов местного значения и развития территории. Работа ТОС может включать благоустройство, поддержку общественных инициатив, сохранение порядка и подготовку проектов, которые помогают сделать село более удобным и комфортным для жизни.

Есть открытая группа ТОС · Год создания: 2014

Источник, дата и объём проверки сведений пока не зафиксированы.
