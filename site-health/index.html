Как пользоваться этой страницей

  • Не считать стартовую идею утверждённым проектом, запрос сведений — новостью, а заготовку фотоотчёта — реализованным результатом.
  • Сначала закрывать карточки с высоким приоритетом.
  • Затем повышать статус проверки данных хотя бы у нескольких карточек до «подтверждено».
  • Техническая проверка ссылок подтверждает работоспособность переходов, но не достоверность председателей, контактов, границ, документов и проектов.
  • Исправлять сначала замечания высокого уровня: отсутствующий lang, небезопасные внешние ссылки, изображения без alt.
  • Средние и низкие замечания исправлять по контрольным страницам, не ломая формы и мобильную навигацию.
  • Ручные зависимости вести через `/github-tasks/` и соответствующие GitHub Issues.
  • Домен и публикационный контур проверять отдельно: основной сайт может открываться в браузере, даже если терминальная проверка окружения возвращает 403.
  • GitHub Actions проверять отдельно: сгенерированные файлы могут быть актуальны, даже если commit endpoint не показывает workflow-runs.
  • CSS менять только после проверки карты сопровождения и контрольных страниц.
  • Все выводы нужно сверять с открытыми источниками и председателями ТОС.
