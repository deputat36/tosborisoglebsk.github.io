# Консолидация локальной админ-панели

Дата: 13 июля 2026 года.

## Причина

В каталоге `admin/` накопились две HTML-версии редактора и несколько JavaScript-модулей, которые выполняли одинаковые массовые операции.

Основная страница `/admin/` одновременно подключала `admin-logo-tools.js` и `admin-logo-bulk.js`. Оба модуля добавляли одинаковые кнопки. Отдельная HTML-копия дополнительно подключала три почти одинаковых варианта массового автозаполнения.

## Поддерживаемая реализация

Оставлена одна страница `admin/index.html`.

Текущий архитектурный контракт: одна поддерживаемая HTML-страница и пять модулей в фиксированном порядке:

1. `admin/admin2.js` — основной редактор;
2. `admin/admin-logo-tools.js` — массовые пути логотипов и CSV;
3. `admin/admin-dashboard.js` — обзор и аналитика;
4. `admin/admin-export-tools.js` — CSV текущей выборки;
5. `admin/admin-history.js` — локальные снимки и восстановление.

## Удалённые файлы

- `admin/admin-index-ready.html`;
- `admin/admin.js`;
- `admin/admin-logo-bulk.js`;
- `admin/admin-mass-autofill.js`;
- `admin/admin-mass-fill-all.js`;
- `admin/admin-mass-all-autofill.js`.

Содержимое сохраняется в Git history.

## Служебная очистка

- удалён устаревший путь из SEO skip-list;
- accessibility patcher работает только с актуальной админкой;
- JavaScript syntax-check охватывает `admin/`;
- изменения `admin/**` запускают CI.

## Безопасность

Админка:

- `noindex,nofollow`;
- не хранит GitHub token;
- не обращается к `api.github.com`;
- не делает commit или push;
- сохраняет черновики и историю в браузере;
- создаёт CSV и JSON локально.

Прямая запись в GitHub намеренно не используется.

## Автоматическая защита

- `scripts/audit_admin_consolidation.js` проверяет одну страницу, пять модулей, отсутствие дублей и credential patterns;
- `scripts/audit_admin_safe_tools.js` проверяет CSV, снимки, откат и отсутствие сетевой отправки.

## Границы пакетов

Первый пакет не добавлял функции. Второй добавляет только локальный CSV и историю снимков, не меняя JSON-схемы или публичные данные.
