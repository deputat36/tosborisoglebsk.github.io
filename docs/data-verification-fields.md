# Поля проверки данных карточки ТОС

В `data/toses.json` можно добавить четыре необязательных поля:

```json
{
  "verification_status": "verified",
  "verified_at": "2026-06-14",
  "verification_source": "председатель ТОС",
  "verification_note": "Контакты и границы подтверждены"
}
```

## Допустимые статусы

- `verified` — данные проверены полностью;
- `partial` — подтверждена только часть сведений;
- `needs_review` — карточку нужно перепроверить;
- `unknown` — дата и источник проверки неизвестны.

Статус `stale` формируется автоматически, если с даты `verified_at` или `updated_at` прошло более 180 дней.

## Правила

1. Статус `verified` ставится только после подтверждения сведений ответственным источником.
2. В `verification_source` не нужно публиковать закрытые персональные данные. Достаточно формулировок: «председатель ТОС», «администрация», «официальный документ».
3. `verified_at` отражает дату фактической проверки, а `updated_at` — дату изменения записи на сайте.
4. Если поля проверки отсутствуют, сайт не помечает карточку как полностью проверенную. Статус выводится автоматически как частичная проверка или необходимость уточнения.
5. После изменения `data/toses.json` workflow пересобирает карточки и рабочий аудит.
