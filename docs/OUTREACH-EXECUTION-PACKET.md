# Локальный пакет отправки исходящих запросов

Обновлено: 16 июля 2026 года.

## Назначение

Пакет встроен в `/outreach-register/` и помогает выполнить issue #166 без ручного поиска текста по нескольким файлам.

Он объединяет 15 черновиков из `data/outreach_register.csv` с каноническими источниками:

- `data/priority_tos_requests.csv` — четыре приоритетные карточки;
- `data/candidate_registry_requests.csv` — пять кандидатов реестра;
- `data/projects_2026_result_requests.csv` — пять запросов по проектам, которые ещё не отправлены;
- `/data-requests/tos-registry-request/` — смысл и состав запроса полного реестра.

Строка `out-011` уже имеет статус `resolved` и в пакет отправки не включается.

## Что делает мастер

Для каждого черновика можно:

1. Выбрать задачу.
2. Получить готовый текст из связанного источника.
3. Указать фактический канал, получателя и ответственного.
4. Копировать запрос для ручной отправки.
5. Скачать карточку подготовки.
6. После реальной отправки указать даты и подтвердить действие.
7. Скачать строку `sent` для последующей проверки и ручного внесения в журнал.

Черновик сохраняется только в `localStorage` текущего браузера.

## Откуда берётся текст

- Для кандидатов реестра и проектов используется поле `request_text` исходного CSV без переписывания.
- Для приоритетных карточек текст собирается из названия ТОС, территории и списка недостающих полей.
- Для полного реестра используется нейтральная формулировка, соответствующая странице готового запроса.

Рекомендованный маршрут из `outreach_register.csv` показывается только как подсказка. Он не считается фактическим каналом и не переносится автоматически в экспорт.

## Кнопка «Копировать запрос»

Копирует только текст обращения. После этого сообщение нужно вручную отправить через фактически выбранный канал.

Копирование текста:

- не меняет статус;
- не записывает дату;
- не подтверждает получателя;
- не является следом отправки.

## Кнопка «Скачать карточку подготовки»

Создаёт локальный TXT-файл с:

- идентификатором задачи;
- темой;
- локально введёнными реквизитами;
- готовым текстом;
- рабочим примечанием.

Карточка подготовки не является подтверждением отправки. Её можно использовать как чек-лист или передать ответственному сотруднику.

## Когда появляется экспорт sent

Кнопка «Скачать строку `sent`» остаётся заблокированной, пока одновременно не выполнены условия:

- отмечено «Запрос действительно отправлен»;
- указан фактический канал;
- указан фактический получатель или организация;
- назначен ответственный;
- указана корректная дата отправки;
- указана дата повторного контакта;
- дата повторного контакта не раньше даты отправки;
- исходная строка имеет статус `draft`.

Экспорт содержит одну строку с заголовками `outreach_register.csv`. Он не заменяет весь журнал и не вносится в репозиторий автоматически.

## Порядок после фактической отправки

1. Сохранить допустимый след отправки вне публичного репозитория.
2. В мастере отметить фактическую отправку и заполнить обязательные поля.
3. Скачать строку `sent`.
4. Сверить её с исходной строкой в `data/outreach_register.csv`.
5. Перенести значения в полный CSV отдельным PR.
6. Запустить профильный workflow и общий project-mode.
7. Только после зелёных проверок считать техническую фиксацию завершённой.

## Безопасность

В публичный репозиторий нельзя переносить:

- пароли и токены;
- закрытые ссылки с доступом к аккаунту;
- содержимое личной переписки;
- непубличные телефоны и email;
- закрытые скриншоты;
- персональные сведения, не предназначенные для открытой публикации.

Для поля evidence подходит публичная или обезличенная ссылка. Сам материал при необходимости хранится вне публичного GitHub.

## Границы

Пакет:

- не выполняет отправку;
- не обращается к внешним сервисам записи;
- не изменяет `data/outreach_register.csv`;
- не ставит дату автоматически;
- не создаёт фиктивный ответ;
- не закрывает issue #166.

Issue #166 закрывается только после фактической обработки всех 15 черновиков и честного обновления журнала.
