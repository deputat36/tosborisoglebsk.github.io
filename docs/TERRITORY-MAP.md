# Карта территорий ТОС БГО

## Для жителя

Откройте `/map/`, найдите ТОС по названию или населённому пункту. Если проверенный контур опубликован, кнопка «Показать границу» приблизит его; карточка ТОС доступна всегда. Ссылка на выбранный ТОС открывает общую карту с параметром `?tos=slug` и не передаёт рабочую разметку.

Нажатие на карту объясняет, какие нанесённые границы относятся к точке. Если контура нет, показывается маршрут создания ТОС и предложение уточнить реестр. Внешний контур округа используется как ориентир. Отсутствие контура ТОС не доказывает отсутствие зарегистрированного ТОС или допустимость создания нового.

## Как Алексею отметить территории

1. Нажать «Моя разметка». Выбрать существующий ТОС из каталога либо тип «Идея нового ТОС» и рабочее название.
2. При необходимости включить «Показать улицы». По умолчанию внешняя подложка не загружается.
3. Нажать «Нарисовать контур», поставить угловые точки и завершить кнопкой. На телефоне можно передвигать карту и нажимать «Точка в центре карты». Клавиатурой карта перемещается стрелками; координаты можно ввести текстом.
4. Для раздельных частей одного ТОС нарисовать несколько участков. Для двора или территории, не входящей во внешний контур, выбрать участок и «Вырезать участок»: исключение должно целиком находиться внутри него.
5. Выбрать участок в списке, указать основание, источник и публичное пояснение. Нажать «Сохранить описание выбранного участка». Выбор «По указанному документу» не делает границу проверенной автоматически.
6. Для точной правки раскрыть «Правка вершин и координат»: двигать точки или вводить широту и долготу по одной паре в строке. При исключениях сначала выбрать нужный контур. Внешний контур и исключения сохраняются отдельно.
7. Проверить пересечения. Наложения схем и выход за ориентировочный контур округа требуют уточнения; это не заключение о правовом споре. Касание смежных границ не считается наложением площади.
8. Нажать «Скачать разметку». Передать GeoJSON редактору/в этот чат для проверки и общей публикации. Для обсуждения доступны CSV с приблизительными площадями и SVG-схема без тайлов улиц.

Изменения сохраняются в этом браузере. Другой браузер или устройство их не увидит без переноса файла. Очистка браузерных данных удалит локальную копию. Если браузер запрещает сохранение, скачивание остаётся доступно. Повреждённая старая запись не перезаписывается автоматически; «Очистить мою разметку» после подтверждения позволяет начать заново. При изменении из другой вкладки скачайте нужную версию и обновите страницу.

## Как публиковать общие границы

Файл автора является черновиком. Не переносить статус автора, реквизиты документа или контур в verified без проверки. Сверить актуальные документы/реестр, состав участков, исключения, смежные ТОС, реквизиты и разрешённость публичного источника. Не публиковать личные адреса, телефоны и сведения жителей.

Для каждого публичного Feature в `data/toses.geojson` обязательны:

| Поле | Содержание |
| --- | --- |
| `slug` | Существующий идентификатор каталога |
| `verification_status` | Только `verified` после проверки |
| `geometry_role` | `boundary` для Polygon/MultiPolygon; `reference_point` для Point |
| `source` | Документ или проверяемый источник, позволяющий установить происхождение |
| `checked_at` | Реальная дата проверки YYYY-MM-DD |
| `public_note` | Понятное посетителю описание назначения и ограничений геометрии |

Point остаётся ориентиром и не заменяет территорию. Геометрии должны иметь конечные координаты долгота/широта, замкнутые непересекающиеся кольца и корректные исключения. Сохранить официальный исходник и его условия использования отдельно; картографическая схема не заменяет правовой акт.

После изменения данных: `node scripts/generate_territory_map.js`, `node scripts/test_territory_map_core.js`, `node scripts/audit_map_content.js`, полный `npm run audit:all`, браузерные проверки CI. Генерация встраивает актуальную карту и минимальный каталог в HTML: повторный запрос данных для первого показа не требуется. Канонический публичный файл сейчас пуст; координаты существующих ТОС не выдумывались.

## Источники и стоимость

Контур округа: [OSM relation 937332](https://www.openstreetmap.org/relation/937332), [API](https://www.openstreetmap.org/api/0.6/relation/937332/full.json), получен 2026-11-12. Версия 33, дата редакции 2023-08-25. Один внешний контур: 58 исходных отрезков соединены по ID узлов, 1184 вершины с замыканием; без упрощения. Лицензия ODbL 1.0, © OpenStreetMap contributors. `data/bgo-reference.geojson` содержит происхождение и признак `reference_only`; схема не равнозначна официальной границе муниципалитета.

Leaflet 1.9.4 с лицензией BSD-2-Clause хранится в `assets/vendor/leaflet/`. Тайлы — стандартный сервис OpenStreetMap: [правила использования](https://operations.osmfoundation.org/policies/tiles/). Нужна видимая атрибуция; обычные браузерные запросы, Referer и кэширование сохраняются. Нет предзагрузки, прокси для тайлов, скачивания подложки, офлайн-пакетов или автоматического прогрева. Браузерные тесты подменяют запросы при проверке кнопки. Доступность внешней подложки не гарантируется; собственные контуры и экспорт работают без неё.

Новые платные услуги, ключи, подписки и серверное хранилище не добавлены. Разметка не записывается на сервер; общая публикация проходит существующий редакционный процесс. Исходная геометрия округа и библиотека размещены на текущем хостинге.

## Дополнительная польза без нового бюджета

Уже доступны: обсуждение вариантов нового ТОС, проверка стыков участков, ссылка на ТОС, схема для собрания, приблизительная площадь, таблица участков и перенос разметки между устройствами. Площадь — геометрическая оценка в гектарах; суммы могут содержать наложения и не означают официальную площадь охвата или свободной земли.

Следующий этап после проверки реальных границ: связать с контурами существующие новости, результаты и проекты через `tos_slug`; показывать «Что сделано рядом», открытые потребности и инициативы. Для точек проекта потребуются реальные координаты и основание публикации, их нельзя выводить из названия улицы. Можно сравнивать изменения охвата по датированным проверенным наборам; без полного реестра нельзя объявлять процент юридически свободной территории. Опросы и обращения можно готовить существующими формами сайта, сохраняя различие между подготовленным текстом и фактом его отправки.

Для премии «Служение» демонстрировать рабочий сценарий и подтверждённое использование: сколько реальных контуров проверено, сколько участников подготовили разметку, какие решения приняли на её основе. Возможности редактора не выдавать за достигнутый общественный результат, тестовую разметку не включать в общую карту.
