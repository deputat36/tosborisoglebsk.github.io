# Матрица приёмки персонального плана наполнения

| Сценарий | Ожидаемый результат |
|---|---|
| У ТОС нет содержательной новости | Показана адресная кнопка подготовки новости и ссылка на фотоотчёт |
| У ТОС нет истории результата | Показана кнопка оформления результата через сценарий фотоотчёта |
| У ТОС нет актуальной потребности | Показана кнопка оформления потребности |
| Категория уже представлена содержательной публикацией | Повторный запрос этой категории не показывается |
| Есть только редакционный запрос | Категория остаётся незакрытой |
| Появилась содержательная публикация | Действие исчезает после следующей генерации |
| Пользователь нажимает адресную кнопку | В конструкторе выбран нужный ТОС и нужный сценарий |
| Карточка имеет несколько пробелов | Показаны только фактически отсутствующие категории |
| Карточка имеет один пробел | Показано одно точечное действие без повторных просьб |
| На портале нет записи | Интерфейс не утверждает, что ТОС не ведёт работу |
