# Безопасные инструменты локальной админки

Дата: 13 июля 2026 года.

## Цель

Добавить два практических инструмента поверх консолидированной админ-панели без сервера, токенов и прямой записи в GitHub:

1. CSV-экспорт текущей отфильтрованной выборки;
2. локальные снимки данных с восстановлением последнего состояния.

## CSV текущего списка

Модуль: `admin/admin-export-tools.js`.

Кнопка «CSV текущего списка» экспортирует только записи, которые видны при активных поиске и фильтре.

Правила экспорта:

- используются данные действующей функции `filtered()`;
- порядок основных полей стабилен: slug, id, name, title, status, type, date, location, chairperson, tos_slug;
- остальные найденные поля добавляются в алфавитном порядке;
- массивы соединяются через ` | `;
- вложенные объекты сериализуются в JSON;
- CSV использует разделитель `;`;
- значения экранируются двойными кавычками;
- добавляется UTF-8 BOM для корректного открытия в Excel;
- имя файла содержит раздел и дату;
- пустая выборка не создаёт файл и показывает предупреждение.

Экспорт не отправляет данные по сети. Файл создаётся через Blob в браузере и скачивается на устройство пользователя.

## Локальные снимки и откат

Модуль: `admin/admin-history.js`.

Для каждого раздела используется отдельный ключ `localStorage`:

```text
tosbgo_admin_history_<section>
```

Возможности:

- ручная кнопка «Создать снимок»;
- кнопка «Откатить» с количеством доступных снимков;
- максимум 10 снимков на раздел;
- дата, причина и количество записей в каждом снимке;
- одинаковые последовательные состояния не дублируются;
- перед восстановлением показывается подтверждение;
- перед откатом текущее состояние сохраняется как `before-restore`;
- после восстановления обновляются список и форма;
- для каталога ТОС очищается кеш вариантов `tos_slug`.

Автоматический снимок создаётся перед:

- импортом JSON;
- добавлением записи;
- удалением записи;
- дублированием;
- одиночным автозаполнением;
- формированием пути логотипа;
- массовым заполнением путей логотипов.

## Ограничения

- снимки хранятся только в текущем браузере и на текущем устройстве;
- очистка данных браузера удалит историю;
- localStorage не заменяет общий JSON-backup;
- CSV может содержать опубликованные контакты, поэтому перед передачей файла нужно проверить его назначение;
- откат меняет только локальный черновик и не влияет на GitHub;
- публикация по-прежнему выполняется скачиванием JSON и ручной заменой файла в репозитории.

## Безопасность

Модули:

- не содержат GitHub token;
- не обращаются к `api.github.com`;
- не используют `fetch`, XMLHttpRequest или WebSocket;
- не делают commit или push;
- не отправляют содержимое CSV или снимков внешним сервисам.

## Автоматическая защита

`scripts/audit_admin_safe_tools.js` проверяет:

- наличие и порядок двух модулей в `admin/index.html`;
- использование текущей выборки при CSV-экспорте;
- BOM, экранирование и имя экспортируемого файла;
- лимит `MAX_SNAPSHOTS = 10`;
- отдельный ключ истории для каждого раздела;
- перечень автоматических снимков;
- `before-restore` и подтверждение отката;
- сохранение данных через localStorage;
- отсутствие сетевых API и credential patterns;
- наличие инструкции для пользователя;
- подключение проверки к package и project-mode audits.

## Границы пакета

Пакет не меняет JSON-схемы, публичные страницы или данные. Добавление новых коллекций в редактор должно выполняться отдельным PR со schema-аудитом.
