# Состояние проекта

Обновлено: 18 июня 2026 года.

## Реализовано

- публичный каталог и отдельные карточки ТОС;
- новости, проекты, потребности, события и истории результатов;
- разделы для жителей, партнёров и председателей;
- комплекты документов для собраний, проектов и создания ТОС;
- правовой навигатор;
- рабочий аудит заполненности и проверки карточек;
- автоматическая генерация страниц и sitemap;
- проверки JSON, SEO и внутренних ссылок;
- интерактивный центр передачи материалов в разделе `/update-tos/`;
- рабочий аудит сайта и план улучшений в `docs/AUDIT-2026-06-18.md`;
- подготовлен публичный блок статуса сведений для карточек ТОС.

## Текущий этап

Повышение доверия к карточкам ТОС: публично показывать статус сведений, не выдавать непроверенные данные за подтверждённые и направлять жителей/председателей в правильный сценарий уточнения.

## Последнее улучшение

Проведён аудит текущей структуры портала. Проверен пользовательский путь через конструктор `/update-tos/`, добавлена совместимость старых сценарных ссылок, обновлены входы на конструктор с главной страницы и страницы новостей, а технический отчёт состояния сайта усилен проверкой внутренних якорей.

В следующей ветке доработан генератор карточек ТОС: добавлен публичный статус сведений, а старые ссылки из карточек заменены на сценарные ссылки конструктора `/update-tos/?tos=<slug>&type=<scenario>#message-builder`.

## Следующие задачи

1. Смержить доработку генератора карточек ТОС и дождаться автогенерации страниц.
2. Проверить несколько карточек ТОС после публикации: статус сведений, кнопки уточнения, кнопки новости, проекта, потребности и фотоотчёта.
3. Получить подтверждение сведений по карточкам высокого приоритета.
4. Добавить проверенные новости, проекты, потребности и результаты по каждому ТОС.
5. Подготовить публичный пакет запуска портала и обращение к председателям.
6. Регулярно отслеживать устаревшие данные через `/audit/` и отчёт состояния сайта.
