# Состояние проекта

Обновлено: 18 июня 2026 года.

## Реализовано

- публичный каталог и отдельные карточки ТОС;
- новости, проекты, потребности, события и истории результатов;
- разделы для жителей, партнёров и председателей;
- комплекты документов для собраний, проектов и создания ТОС;
- правовой навигатор;
- рабочий аудит заполненности и проверки карточек;
- автоматическая генерация страниц и sitemap;
- проверки JSON, SEO, JS-синтаксиса и внутренних ссылок;
- интерактивный центр передачи материалов в разделе `/update-tos/`;
- рабочий аудит сайта и план улучшений в `docs/AUDIT-2026-06-18.md`;
- подготовлен публичный блок статуса сведений для карточек ТОС;
- улучшена страница `/data-quality/` с пояснением статусов проверки;
- добавлена памятка `/chairperson/verify-card/` для подтверждения карточки ТОС.

## Текущий этап

Повышение доверия к карточкам ТОС: публично показывать статус сведений, не выдавать непроверенные данные за подтверждённые и направлять жителей и председателей в правильный сценарий уточнения.

## Последнее улучшение

Проведён аудит текущей структуры портала. Проверен пользовательский путь через конструктор `/update-tos/`, добавлена совместимость старых сценарных ссылок, обновлены входы на конструктор с главной страницы и страницы новостей, а технический отчёт состояния сайта усилен проверкой внутренних якорей.

Доработан генератор карточек ТОС: добавлен публичный статус сведений, а старые ссылки из карточек заменены на сценарные ссылки конструктора `/update-tos/?tos=<slug>&type=<scenario>#message-builder`.

Раздел `/data-quality/` теперь объясняет разницу между заполненностью и подтверждением сведений. Для председателей добавлена отдельная памятка `/chairperson/verify-card/` с чек-листом и готовым текстом для отправки уточнений.

## Следующие задачи

1. Дождаться автогенерации страниц и проверить опубликованные карточки ТОС.
2. Проверить статус сведений и кнопки уточнения, новости, проекта, потребности и фотоотчёта.
3. Получить подтверждение сведений по карточкам высокого приоритета: Ивановка, Подстёпки, Губари, Танцырей.
4. Перевести первые подтверждённые карточки в статус `verification_status: verified` с датой и источником.
5. Добавить проверенные новости, проекты, потребности и результаты по каждому ТОС.
6. Подготовить публичный пакет запуска портала и обращение к председателям.
7. Регулярно отслеживать устаревшие данные через `/audit/` и отчёт состояния сайта.
