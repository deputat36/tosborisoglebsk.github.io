# Состояние проекта

Обновлено: 14 июня 2026 года.

## Реализовано

- публичный каталог и отдельные карточки ТОС;
- новости, проекты, потребности, события и истории результатов;
- разделы для жителей, партнёров и председателей;
- комплекты документов для собраний, проектов и создания ТОС;
- правовой навигатор;
- рабочий аудит заполненности и проверки карточек;
- автоматическая генерация страниц и sitemap;
- проверки JSON, SEO и внутренних ссылок;
- интерактивный центр передачи материалов в разделе `/update-tos/`.

## Текущий этап

Повышение качества фактических данных и упрощение передачи материалов председателями и активистами.

## Последнее улучшение

Центр `/update-tos/` переведён из набора статических шаблонов в интерактивный конструктор сообщения. Он использует актуальный список ТОСов, добавляет ссылку на карточку, проверяет обязательные поля, сохраняет черновики по каждому типу материала локально и формирует готовый текст для редакции.

## Следующие задачи

1. Получить подтверждение сведений по карточкам высокого приоритета.
2. Добавить проверенные новости, проекты, потребности и результаты по каждому ТОС.
3. Подготовить публичный пакет запуска портала и обращение к председателям.
4. Регулярно отслеживать устаревшие данные через `/audit/`.
