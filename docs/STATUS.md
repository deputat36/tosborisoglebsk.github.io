# Состояние проекта

Обновлено: 15 июня 2026 года.

## Реализовано

- публичный каталог и отдельные карточки ТОС;
- новости, проекты, потребности, события и истории результатов;
- разделы для жителей, партнёров и председателей;
- комплекты документов для собраний, проектов и создания ТОС;
- правовой навигатор;
- рабочий аудит заполненности и проверки карточек;
- автоматическая генерация страниц и sitemap;
- проверки JSON, SEO и внутренних ссылок;
- интерактивный центр передачи материалов в разделе `/update-tos/`;
- персональные ссылки на обновление данных и отправку материалов для каждого ТОС;
- готовые обращения по карточкам высокого приоритета.

## Текущий этап

Повышение качества фактических данных и упрощение передачи материалов председателями и активистами.

## Последнее улучшение

Карточки ТОС и рабочий аудит связаны с конструктором через персональные адреса вида `/update-tos/?tos=ivanovka&type=news`. Пользователю не нужно повторно выбирать ТОС и тип материала. В `/audit/` добавлены быстрые действия и расширенный текст обращения, а копирование запроса автоматически отмечает статус «Запрос отправлен».

Старые ссылки вида `/update-tos/#template-project` продолжают работать через слой совместимости и переводятся на новый сценарий конструктора.

Для ТОСов «Ивановка», «Подстёпки», «Губари» и «Танцырей» подготовлены персональные обращения в `docs/outreach/high-priority-requests.md`.

## Следующие задачи

1. Отправить подготовленные обращения ответственным представителям ТОСов высокого приоритета.
2. Внести только подтверждённые контакты и сведения в `data/toses.json`.
3. Добавить проверенные новости, проекты, потребности и результаты по каждому ТОС.
4. Подготовить публичный пакет запуска портала.
5. Регулярно отслеживать устаревшие данные через `/audit/`.
