# Состояние проекта

Обновлено: 19 июня 2026 года.

## Реализовано

- публичный каталог и отдельные карточки ТОС;
- новости, проекты, потребности, события и истории результатов;
- разделы для жителей, партнёров и председателей;
- комплекты документов для собраний, проектов и создания ТОС;
- правовой навигатор;
- рабочий аудит заполненности и проверки карточек;
- автоматическая генерация страниц и sitemap;
- проверки JSON, SEO, JS-синтаксиса и внутренних ссылок;
- интерактивный центр передачи материалов в разделе `/update-tos/`;
- рабочий аудит сайта и план улучшений в `docs/AUDIT-2026-06-18.md`;
- подготовлен публичный блок статуса сведений для карточек ТОС;
- улучшена страница `/data-quality/` с пояснением статусов проверки;
- добавлена памятка `/chairperson/verify-card/` для подтверждения карточки ТОС;
- улучшен поиск по инструкциям председателя;
- улучшено мобильное меню сайта;
- добавлена runtime-защита старых карточек ТОС до полной автогенерации;
- расширена внутренняя памятка редактора по ручному запуску GitHub Actions;
- подготовлен публичный коммуникационный набор для запуска портала;
- улучшена рабочая страница `/data-requests/` для первоочередного сбора подтверждений;
- создана GitHub-задача #34 для подтверждения четырёх карточек высокого приоритета;
- в задачу #34 добавлены готовые короткие сообщения для отправки по каждому из четырёх ТОСов;
- в `/communication-kit/` добавлен публичный пост для сбора сведений по Ивановке, Подстёпкам, Губарям и Танцырею;
- повторно обновлён `data/regeneration_request.json` для запроса пересборки сгенерированных карточек.

## Текущий этап

Переход от технической подготовки к запуску и сбору подтверждённых сведений: показать председателям и жителям, как проверить карточки, прислать открытые данные, новости, проекты, потребности и фотоотчёты.

## Последнее улучшение

Проведён аудит текущей структуры портала. Проверен пользовательский путь через конструктор `/update-tos/`, добавлена совместимость старых сценарных ссылок, обновлены входы на конструктор с главной страницы и страницы новостей, а технический отчёт состояния сайта усилен проверкой внутренних якорей.

Доработан генератор карточек ТОС: добавлен публичный статус сведений, а старые ссылки из карточек заменены на сценарные ссылки конструктора `/update-tos/?tos=<slug>&type=<scenario>#message-builder`.

Раздел `/data-quality/` теперь объясняет разницу между заполненностью и подтверждением сведений. Для председателей добавлена отдельная памятка `/chairperson/verify-card/` с чек-листом и готовым текстом для отправки уточнений.

Старые открытые PR разобраны: полезные части перенесены точечно, устаревшие ветки закрыты. В поиск добавлены отдельные инструкции председателя, а мобильное меню теперь закрывается по Escape, клику вне меню и переходу по ссылке.

Добавлена runtime-защита для страниц `/tos/<slug>/`: пока HTML-карточки не пересобраны генератором, `site.js` исправляет старые ссылки `/update-tos/#template-*` на сценарные URL и добавляет блок статуса сведений из `/data/tos_content_audit.json`.

Внутренняя памятка редактора `_private/editor-guide.md` дополнена ручным запуском workflow `Generate TOS pages`, признаками успешной генерации и чек-листом проверки карточек.

Страница `/communication-kit/` расширена до публичного пакета запуска: закреплённый пост, короткий анонс, сообщение председателю, персональный шаблон с `SLUG-ТОС` и ссылки на сценарии `/update-tos/`.

Страница `/data-requests/` теперь содержит прямые сценарные ссылки в сообщениях и отдельный блок «Первые 4 карточки для обработки»: Ивановка, Подстёпки, Губари, Танцырей.

Создана рабочая задача GitHub #34 «Получить подтверждение сведений по 4 карточкам высокого приоритета» с чек-листом, ссылками на карточки и ссылками на формы уточнения. В задачу добавлен комментарий с короткими готовыми сообщениями для отправки по Ивановке, Подстёпкам, Губарям и Танцырею.

В `/communication-kit/` добавлен отдельный публичный пост для ВК «Нужны сведения по 4 ТОСам», чтобы быстро собрать данные по Ивановке, Подстёпкам, Губарям и Танцырею.

Проверка показала, что HTML-карточка `/tos/ivanovka/` всё ещё содержит старые ссылки `/update-tos/?tos=ivanovka` и `/update-tos/#template-*`. Поэтому `data/regeneration_request.json` повторно обновлён 19 июня 2026 года с явным списком карточек для проверки после пересборки.

## Следующие задачи

1. Проверить, появился ли новый автокоммит `Generate SEO pages, sitemap and audit` после повторного обновления `data/regeneration_request.json`.
2. Проверить опубликованные карточки ТОС: статус сведений, кнопки уточнения, новости, проекта, потребности и фотоотчёта.
3. Если автогенерация не прошла, проверить GitHub Actions вручную в интерфейсе репозитория.
4. Использовать `/communication-kit/` для публикации закреплённого поста и обращения к председателям.
5. Использовать `/data-requests/`, GitHub-задачу #34 и отдельный пост в `/communication-kit/` для первоочередной отправки запросов по Ивановке, Подстёпкам, Губарям и Танцырею.
6. Перевести первые подтверждённые карточки в статус `verification_status: verified` с датой и источником.
7. Добавить проверенные новости, проекты, потребности и результаты по каждому ТОС.
8. Регулярно отслеживать устаревшие данные через `/audit/` и отчёт состояния сайта.
