## Поведение файла проверки

JSON содержит только пользовательские отметки, выбор возможности, время сохранения и снимок состава требований. Импорт ограничен 256 КБ, схемой и допустимыми идентификаторами. Источники и подписи для показа берутся из текущего каталога, не из файла. Повреждённый файл не меняет текущее состояние. При изменении списка, документов или условий его отметки не применяются; другие возможности сохраняют свои независимые отметки.

Самопроверка не объединяется с заполненными личными полями проекта. Существующий комплект проекта и его файлы совместимы с прежней версией. Сервер, личные контакты, согласия, уставы и результаты жеребьёвки не изменяются.

## Проверка выпуска

Обязательны сценарии: сохранение и повторное открытие после перезагрузки; независимость двух конкурсов с общими вопросами; сохранение текущих отметок после ошибки чтения; повторная проверка при изменении источника; неизвестный сезон; чтение статического содержания без JavaScript. Полная сборка, применимые аудиты, CI и production smoke подтверждаются результатами выпуска в GitHub.
