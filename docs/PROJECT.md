# Портал ТОС Борисоглебского городского округа

## Назначение

Публичный информационный и рабочий портал для жителей, председателей, активистов и партнёров территориального общественного самоуправления Борисоглебского городского округа.

## Репозиторий и рабочая ветка

- Репозиторий: `deputat36/tosborisoglebsk.github.io`
- Основная рабочая ветка: `release-2025-12-22`
- `main` не используется как основная ветка без отдельного решения владельца.

## Основные разделы

- каталог и карточки ТОС;
- новости, события, проекты, потребности и результаты;
- разделы для жителей, партнёров и председателей;
- инструкции и печатные шаблоны документов;
- правовой навигатор;
- рабочий аудит заполненности карточек;
- центр обновления данных и передачи материалов.

## Данные

Основные сведения хранятся в JSON-файлах каталога `data/`. Материалы связываются с конкретным ТОС через `tos_slug`, совпадающий со `slug` в `data/toses.json`.

## Автоматизация

Скрипты из каталога `scripts/` генерируют страницы, аудит и sitemap. GitHub Actions проверяет данные, SEO и внутренние ссылки. Перед изменением генератора необходимо учитывать все создаваемые им страницы.

## Правила публикации

- не придумывать факты, даты, имена, суммы и адреса;
- непроверенные сведения помечать как требующие уточнения;
- не публиковать закрытые персональные данные и секреты;
- сохранять мобильную адаптивность и единый стиль;
- после структурных изменений проверять `/audit/`, ссылки, sitemap и GitHub Actions.
