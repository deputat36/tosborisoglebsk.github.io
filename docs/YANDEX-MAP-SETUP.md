# Подложка улиц под границами ТОС

## Что работает сразу

Страница `/map/` открывает Борисоглебск на масштабе 14 с обычной подложкой OpenStreetMap: улицы, здания, названия и другие имеющиеся в источнике объекты. На подробных масштабах появляются дополнительные подписи, включая номера домов там, где они внесены в источник. Контуры ТОС рисуются поверх карты; сплошная серая заливка округа отключена при включённой подложке.

Есть метрическая шкала, регулируемая заливка ТОС (включая нулевую), подписи участков и прицел в центре при рисовании. Выбор подложки не изменяет координаты и сохранённую разметку. При ошибке загрузки появляется понятный статус и кнопка повтора; редактор и скачивание файла остаются доступны.

Данные подложки не заменяют проверенные документы о границах ТОС. Каталог, публичные геометрии и локальные наброски остаются отдельными наборами. Экспорт GeoJSON/CSV/SVG включает рабочую разметку и ориентировочный контур, без изображений подложки.

## Как подключить именно Яндекс без покупки лицензии

Подготовлен официальный **Tiles API**. По официальному описанию, проверенному 2026-11-12, он предоставляется бесплатно на постоянной основе при соблюдении условий, в пределах 30 запросов/с. Это самостоятельный продукт: ключ другого API может не подходить.

1. Владелец открывает [Кабинет разработчика Яндекса](https://developer.tech.yandex.ru/), входит со своим Яндекс ID и подключает пакет **Tiles API** на бесплатных условиях. Аккаунт, принятие условий и ключ контролирует владелец; их нельзя создавать автоматически или подменять чужим ключом.
2. В настройках ключа указывает разрешённый домен `tosborisoglebsk.ru`, без протокола и пути. Дополнительные технические домены добавляются только при реальной необходимости. Секрет подписи, OAuth-токены и серверные секреты на сайт не передаются.
3. Передаёт редактору публичный браузерный ключ **Tiles API** для этой карты. Ключ является частью клиентских запросов, поэтому обязательно ограничение по Referer. Не использовать вместо него секрет другого сервиса.
4. Редактор добавляет ключ в `data/map-basemaps.json` как `yandexTilesKey`; для выбора по умолчанию меняет `defaultProvider` с `osm` на `yandex`.
5. Запускаются генератор, проверки и публикация. После активации ключа и ограничений Яндекс предупреждает о возможном ожидании до 15 минут. Работа реального ключа проверяется отдельно; автоматические тесты используют фиктивный ключ и подменённые ответы.

Без ключа Яндекса в интерфейсе нет неработающего пункта переключения. Работает OSM. После подключения появится выбор OpenStreetMap / Яндекс Карты, с сохранением границ ТОС в обеих подложках. При отказе Яндекса карта переключается на OSM с пояснением.

## Технические и лицензионные условия

- Используется только официальный `https://tiles.api-maps.yandex.ru/v1/tiles/`, с `projection=web_mercator`, `lang=ru_RU`, `l=map`, `maptype=map`. Стандартная эллиптическая проекция Яндекса не подходит для накладывания наших координат в Leaflet без преобразования.
- Собственные данные поверх тайлов разрешены п. 6.5.1 условий Яндекса. Выводятся официальный логотип со ссылкой на Карты, ссылка «Открыть в Картах» и условия использования. Логотип `assets/img/yandex-tiles-logo.svg` взят без перерисовки из [официального архива](https://download.cdn.yandex.net/tech/ru/zout_maps-tiles/doc/dg_5991b5839950b3d45e6991d40308f5a6/files/yandex_logo.zip), файл `yandex_logo/SVG/yndex_logo_ru.svg`, 88×48 с исходными полями.
- Новые запросы Яндекса распределяются до 10/с в одном браузере; отменённые тайлы исключаются из очереди. Общий лимит 30/с относится ко всему ключу, не к каждому посетителю: его контролирует поставщик. При высокой посещаемости нужно отдельно проверить пределы, не включать платный тариф автоматически.
- Запрашиваются только тайлы видимой области, без массового обхода, предварительной загрузки других масштабов и офлайн-пакетов. Подложка не включается в выгружаемые файлы. Браузерный HTTP-кэш сохраняет условия поставщика; временное кэширование ответов Яндекса ограничено 30 днями по п. 5.1.6. Собственный прокси и долговременный архив карт не добавлены.
- Для OSM сохраняются обычный Referer и кэш браузера, видимая атрибуция и стандартный HTTPS endpoint. Автоматические тесты подменяют все запросы к обоим поставщикам и не расходуют их квоты.

## Почему 2ГИС не подключён как постоянная основа

Актуальный API 2ГИС требует ключ; официальная документация предлагает месячный демодоступ, затем подписку для рабочих ключей. Постоянная бесплатная работа на этих условиях не подтверждена, поэтому платное подключение не включалось. Старые неофициальные адреса тайлов и чужие ключи не используются. Карточки организаций, отзывы, поиск адресов и маршрутизация являются отдельными возможностями поставщиков, не выдаются за функции растровой подложки.
