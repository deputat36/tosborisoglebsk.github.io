# Изоляция модуля nav-v2

Дата проверки: 10 июля 2026 года.

## Вывод

Файлы `nav-v2` не относятся к порталу ТОС БГО. Это фрагмент отдельного приложения «Навигатор сделок» с ролевой моделью, Supabase-сессией и меню для специалистов по недвижимости.

Модуль сейчас не подключён к действующим HTML-страницам портала ТОС и остаётся в репозитории как изолированный, неполный набор файлов.

## Найденные файлы

- `assets/js/nav-v2/admin-guard-v2.js` — проверка профиля и ролей `owner/admin` через Supabase RPC.
- `assets/js/nav-v2/role-menu-v2.js` — ролевое меню для ролей owner, admin, manager, spn, lawyer, broker и viewer.
- `tools/patch_vktg_nav_roles.py` — патчер, рассчитанный на подключение этих модулей к страницам другого приложения.

## Отсутствующие зависимости

Оба JS-модуля импортируют `config/supabase.js`, которого в репозитории нет.

Патчер рассчитан на страницы:

- `dashboard-v2.html`;
- `spn-v2.html`;
- `deals-v2.html`;
- `deal-card-v2.html`;
- `nav-system-check-v2.html`;
- `admin-v2.html`;
- `admin-invite-v2.html`;
- `nav-access-v2.html`;
- `nav-access-audit-v2.html`.

Эти страницы в корне портала ТОС отсутствуют.

## Текущий режим

Статус: `quarantined_in_place`.

До отдельного решения:

1. Не подключать `assets/js/nav-v2/*` к HTML портала ТОС.
2. Не добавлять в этот репозиторий Supabase-конфигурацию Навигатора сделок.
3. Не создавать перечисленные v2-страницы внутри портала ТОС.
4. Не удалять файлы без подтверждения владельца проекта.
5. Не переносить их автоматически, чтобы не потерять возможную историю другого проекта.

## Рекомендуемое решение

После подтверждения владельца выбрать один вариант:

- перенести файлы в репозиторий Навигатора сделок;
- сохранить их в архивной директории вне публичного сайта;
- удалить после проверки, что актуальные версии уже находятся в другом репозитории.

Структурированный реестр хранится в `data/foreign_module_inventory.json`.
