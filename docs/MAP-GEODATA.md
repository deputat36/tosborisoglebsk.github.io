# Геоданные карты ТОС

Публичная страница `/map/` объясняет жителю, как найти территорию и передать схему.
Технические требования предназначены для редактора и разработчика.

Данные хранятся в `data/toses.geojson`, в коллекции `FeatureCollection`.
Пока коллекция пуста, страница прямо сообщает об отсутствии опубликованных точек
и границ и предлагает каталог. Не добавлять предположительные координаты.

Публичный объект должен содержать:

- `slug` — существующий идентификатор ТОС из `data/toses.json`;
- `verification_status: verified` — подтверждение геоданных;
- `geometry_role` — `reference_point` для ориентира или `boundary` для границы;
- `source` — проверяемое основание;
- `checked_at` — дата фактической сверки в формате YYYY-MM-DD;
- `public_note` — понятное читателю пояснение точности и ограничений.

Геометрия `Point` используется только для `reference_point`.
`Polygon` и `MultiPolygon` используются только для `boundary`.
Источник должен позволять проверить координаты полигона или точки.
Порядок координат GeoJSON: долгота, широта.

Точка-ориентир не определяет принадлежность домов к ТОС. Официальный контур
публикуется после сверки решения, схемы и документа о границах. Нельзя выводить
контур из совпадения адреса в текстовом поиске.

Не хранить в свойствах геометрии личные контакты, домашние адреса активистов,
паспортные данные и закрытые доказательства. Рабочие наброски не публикуются.
Проверка: `node scripts/audit_map_content.js`.
