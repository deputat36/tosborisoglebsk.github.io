# Продолжение аудита портала ТОС БГО от 27 июня 2026 года, часть 13

Этот журнал продолжает `docs/AUDIT-CONTINUATION-2026-06-27-PART-12.md` после пункта 115.

## 116. Отдельная машинная проверка RSS-ленты

- добавлен отдельный аудит `scripts/audit_rss_feed_content.js`;
- проверяется наличие `rss.xml` и `data/news.json`;
- проверяются базовые метаданные RSS: XML-декларация, `rss version="2.0"`, `channel`, title, link, description, language, `lastBuildDate`, закрывающий тег RSS;
- проверяется наличие `guid isPermaLink="true"`;
- проверяется, что количество элементов `<item>` совпадает с количеством записей в `data/news.json`;
- проверяется, что каждая запись новостей с `id` имеет соответствующую ссылку вида `https://tosborisoglebsk.ru/news/{id}/` в RSS.

## Рабочее замечание

Сначала была предпринята попытка усилить уже подключённый `scripts/audit_rss.js`: добавить проверку description канала, permalink-guid, количества элементов и минимальной длины description. Полная запись файла была заблокирована инструментом. Чтобы не перезаписывать рабочий аудит и не рисковать общим runner, создан отдельный скрипт.

## Практический эффект

RSS-лента получила дополнительную ручную проверку поверх уже существующего общего аудита. Если исчезнут базовые метаданные канала, permalink-guid, связь с `data/news.json` или отдельные ссылки новостей, отдельный запуск аудита это покажет.

## Ограничения

- `rss.xml` не изменялся;
- `data/news.json` не изменялся;
- `scripts/audit_rss.js` не изменён из-за блокировки инструмента;
- общий runner пока не содержит `scripts/audit_rss_feed_content.js`;
- скрипт запускается отдельно командой `node scripts/audit_rss_feed_content.js`;
- публичные новости, карточки ТОС, статусы и данные не менялись;
- CI/Actions логи не проверялись.
