## Главные проблемы

1. Каталог портала неполный относительно публичной цифры 46 ТОС.
2. Нет ни одной карточки со статусом `verified`.
3. Часть контента выглядит как рабочие заготовки: «приглашает присылать новости», «собираем истории сделанного», «нужно уточнить данные».
4. Без JavaScript каталог показывал `Найдено: 0`, что снижало доверие и качество текстовой версии страницы.
5. Нет реальных фото территорий и логотипов ТОС.
6. CSS и часть JS требуют дальнейшей аккуратной декомпозиции, но это не блокирует запуск.
