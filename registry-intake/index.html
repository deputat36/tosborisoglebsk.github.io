Приём официального реестра ТОС

Когда будет получен актуальный перечень 46 ТОС БГО, его нельзя сразу превращать в карточки. Сначала нужно зафиксировать источник, нормализовать названия, убрать дубли, сверить с текущими 24 карточками и отделить новые ТОС от переименований.

Основное правило

Новая карточка создаётся только после того, как строка реестра прошла сверку: это не дубль, не переименование существующей карточки, есть официальное название, территория и понятный источник. Контакты и медиа добавляются отдельно после проверки разрешений.

Можно делать автоматически

  • Сверить названия с текущими slug карточек.
  • Отметить очевидные совпадения и потенциальные дубли.
  • Подготовить CSV missing-кандидатов.
  • Собрать список строк с неизвестным типом территории.
  • Подготовить черновики новых карточек со статусом `requires_verification`.

Нельзя делать автоматически

  • Публиковать телефоны без разрешения.
  • Считать похожее название новой карточкой без ручной проверки.
  • Повышать статус до `verified` по одному факту наличия в реестре.
  • Добавлять фото и логотипы из сети без источника.
  • Удалять существующие карточки без подтверждения переименования или закрытия ТОС.

Следующий шаг после получения файла

  1. Сохранить исходный файл и источник без правок.
  2. Заполнить `data/registry_intake_checklist.csv` по этапам.
  3. Сверить полный список с `/registry-check/` и `/registry-type-check/`.
  4. Для новых строк заполнить `/new-tos-card/`.
  5. Для контактов и медиа пройти `/publication-consent/`.
  6. Для первых карточек использовать `/verification-evidence/` и `/verification-readiness/`.
