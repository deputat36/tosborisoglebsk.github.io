Локальный редактор в браузере

Редактор открытых данных ТОС БГО

Это публично доступный клиентский инструмент без серверной авторизации. Он загружает открытые JSON-файлы только с этого сайта, хранит черновики в текущем браузере и позволяет скачать результат на компьютер.

Открыть сайт
Это не защищённая админка. На странице нет аккаунтов, серверной сессии, PIN-защиты или разграничения доступа. Не вводите сюда паспорта, подписи, банковские данные, закрытую переписку, оригиналы согласий и непубличные контакты. Черновики в localStorage доступны пользователям этого браузера до ручного сброса.
Публикация выполняется вручную. Редактор не записывает данные в GitHub и не отправляет их на сторонние серверы. После проверки скачайте JSON и замените соответствующий файл в data/ отдельным контролируемым изменением репозитория.

Как пользоваться локальным редактором

  1. Работайте только с данными, которые допустимо хранить в публичном репозитории.
  2. Выберите раздел слева и найдите нужную запись.
  3. Отредактируйте поля. Черновик автоматически сохраняется только в браузере.
  4. Проверьте ошибки и качество записи.
  5. Нажмите «Скачать JSON».
  6. Проверьте diff и только затем замените соответствующий файл в data/.
  7. После завершения нажмите «Сбросить черновики», если компьютером пользуются другие люди.

Разделы

  • data/toses.json — каталог ТОСов.
  • data/news.json — новости.
  • data/articles.json — полезные материалы.
  • data/documents.json — документы.
  • data/grants.json — конкурсы и гранты.
  • data/projects.json — банк идей проектов.
  • data/events.json — календарь событий.
  • data/needs.json — потребности ТОСов и предложения помощи.

Инструмент не хранит пароли и токены, не выполняет серверную авторизацию и не делает сетевые запросы на запись. Его безопасность ограничена браузером, устройством и качеством ручной проверки скачанного файла.
