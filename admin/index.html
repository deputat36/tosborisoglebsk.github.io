Управление сайтом ТОС БГО

Редактирование данных сайта без сервера. Изменения сохраняются в браузере, затем скачиваются JSON-файлом и загружаются в GitHub.

Открыть сайт
Важно. Эта админка не записывает данные прямо в GitHub. После правок скачайте JSON и замените соответствующий файл в папке data/ репозитория.

Как пользоваться админ-панелью

  1. Выберите раздел слева.
  2. Найдите нужную запись или нажмите «Добавить запись».
  3. Отредактируйте поля. Черновик автоматически сохраняется в браузере.
  4. Нажмите «Скачать JSON».
  5. В GitHub замените соответствующий файл в папке data/.

Разделы

  • data/toses.json — каталог ТОСов.
  • data/news.json — новости.
  • data/articles.json — полезные материалы.
  • data/documents.json — документы.
  • data/grants.json — конкурсы и гранты.
  • data/projects.json — банк идей проектов.
  • data/events.json — календарь событий.
  • data/needs.json — потребности ТОСов и предложения помощи.

Админка не хранит пароли и токены. Она работает только с открытыми JSON-файлами и скачивает обновлённую версию на ваш компьютер.
