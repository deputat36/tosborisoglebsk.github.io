# Портал ТОС Борисоглебского городского округа

Сайт: `https://tosborisoglebsk.ru`

Репозиторий содержит публичный портал территориального общественного самоуправления Борисоглебского городского округа: каталог ТОСов, новости, проекты, потребности, события, документы, правовой раздел и рабочие инструменты для председателей.

## Рабочая ветка

Основная ветка разработки и публикации: `release-2025-12-22`.

Ветка `main` не используется как основная без отдельного решения владельца проекта.

## Структура

- `data/` — данные сайта в JSON;
- `scripts/` — генераторы страниц, sitemap и аудита;
- `assets/` — стили, JavaScript и изображения;
- `tos/` — сгенерированные карточки ТОС;
- `documents/` — документы и шаблоны;
- `chairperson/` — практический раздел для председателей;
- `audit/` — рабочий аудит данных;
- `docs/` — документация проекта.

## Связь материалов

Новости, проекты, события, потребности и результаты связываются с карточкой ТОС через поле `tos_slug`. Оно должно совпадать со `slug` в `data/toses.json`.

## Автоматическая проверка

Workflow `.github/workflows/generate-tos-pages.yml` проверяет JSON, пересобирает страницы, аудит и sitemap, а также выполняет проверку внутренних ссылок и базового SEO.

## Документация

- `AGENTS.md` — правила работы с проектом;
- `docs/PROJECT.md` — устройство проекта;
- `docs/STATUS.md` — текущее состояние;
- `docs/DECISIONS.md` — важные технические решения.
