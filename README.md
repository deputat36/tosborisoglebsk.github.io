# Портал ТОС Борисоглебского городского округа

Готовый статический сайт для GitHub Pages.

## Что внутри

- Главная страница
- Каталог 24 ТОСов
- Отдельные страницы каждого ТОС
- Новости
- Методические материалы
- Документы
- Раздел «Как создать ТОС»
- Заготовка карты
- Контакты
- CNAME для домена tosborisoglebsk.ru

## Как обновлять

- `data/toses.json` — каталог ТОС
- `data/news.json` — новости
- `data/articles.json` — материалы
- `data/documents.json` — документы
