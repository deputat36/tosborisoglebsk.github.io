Правило закрытия

Страница, шаблон, CSV или зелёный технический audit не закрывают внешний блокер сами по себе. Нужны фактическая отправка, официальный источник, ручная проверка Settings → Pages, проверяемый ответ или юридическое решение.

После изменения GitHub Issue локальный реестр и очередь решений обновляются отдельным проверяемым PR. Ссылки на закрытые issues не сохраняются как открытые задачи.
