Правило закрытия

Зелёный audit, заполненный шаблон или появление готовой строки не закрывают внешний блокер. Нужны фактическая отправка, официальный источник, ручная проверка Settings → Pages, проверяемый ответ либо отдельное утверждённое решение.

После реального изменения GitHub Issue локальный реестр обновляется отдельным проверяемым PR. Закрытые issues исключаются из набора открытых карточек.
