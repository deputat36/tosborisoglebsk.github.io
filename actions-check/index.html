Правило интерпретации

Успешный PR-run подтверждает код и проверки в merge-ref pull request. Он не доказывает, что изменения уже находятся в default branch или опубликованы через GitHub Pages.

Успешный push-run подтверждает workflow основной ветки, но публикацию нужно дополнительно сверить по Pages deployment и внешним URL.
