Итог проверки на 2 июля 2026 года

Рабочий репозиторий проекта подтверждён: deputat36/tosborisoglebsk.github.io. Рабочая ветка совпадает с default branch: release-2025-12-22.

Workflow Generate TOS pages найден в .github/workflows/generate-tos-pages.yml. Он запускается вручную, по расписанию и при push в рабочую ветку по файлам страниц, данных, скриптов, стилей, логотипов и самого workflow.

Через доступный commit endpoint по последним автономным коммитам получен пустой список workflow_runs. Это не доказывает ошибку деплоя. Поэтому результат генерации дополнительно контролируется по файлам data/site_health.json, rss.xml, sitemap.xml и data/page_index.json, а GitHub Actions UI нужно проверить вручную.

Что проверено

  • репозиторий и ветка проекта;
  • наличие workflow генерации;
  • триггеры workflow;
  • commit endpoint по автономным коммитам;
  • наличие обновлённого site_health.json.

Что требует ручного контроля

  • открыть вкладку GitHub Actions;
  • проверить последний запуск Generate TOS pages;
  • при ошибке скачать логи job;
  • сверить GitHub Pages deployment;
  • после ручной проверки обновить CSV и задачу #164.

Правило фиксации результата

В документации нельзя писать «CI проверен», если доступны только производные файлы. Корректная формулировка: «генерация подтверждена по сгенерированным файлам и отчёту здоровья; журналы GitHub Actions требуют ручной проверки через Actions UI».
