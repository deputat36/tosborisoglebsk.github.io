Подтверждённые этапы

  1. ТОС подготовил культурный проект «Русские традиции — в каждый ТОС».
  2. В 2023 году проект был реализован.
  3. Для мероприятий приобрели необходимое звуковое оборудование.
  4. Для проведения культурных программ приобрели костюмы.
  5. Проект вошёл в последовательную линейку инициатив ТОС «Чкаловец», подтверждённую ретроспективным материалом РИА «Воронеж».
