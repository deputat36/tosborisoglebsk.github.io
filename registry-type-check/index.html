Кандидаты без подтверждённого типа

  • Горелка;
  • Хоперский берег;
  • Тюковка;
  • Ручей.

Эти названия нельзя автоматически распределять в городские или сельские. Для каждого нужен источник: официальный реестр, документ администрации или ответ председателя/координатора.

Как сверять тип

  1. Проверить, указан ли ТОС в официальном реестре.
  2. Сверить населённый пункт и границы.
  3. Не считать тип только по названию.
  4. Для спорных строк оставить статус «тип требует проверки».
  5. После подтверждения обновить карточку и CSV сверки.
